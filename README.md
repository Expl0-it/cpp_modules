# 📘 CPP Modules

A comprehensive collection of C++ exercises and mini-projects following the **42 School C++ curriculum**, designed to build a strong foundation in **Object-Oriented Programming (OOP)** and modern C++ concepts.

---

## 📖 Overview

This repository contains a structured series of modules (from **Module 00 to Module 09**) that progressively introduce key C++ features. Each module consists of multiple exercises focusing on specific concepts, helping developers transition from procedural programming (C) to object-oriented design in C++.

The project emphasizes:

* Clean and modular code
* Deep understanding of C++ fundamentals
* Practical implementation of OOP principles
* Compilation using the **C++98 standard** (as required by 42 curriculum)

---

## 🧠 Learning Objectives

By completing these modules, you will gain experience with:

* Object-Oriented Programming (OOP)
* Memory management (stack vs heap)
* Classes, inheritance, and polymorphism
* Operator overloading
* Templates and generic programming
* Exception handling
* STL (Standard Template Library)
* File I/O and parsing
* Algorithmic problem solving

## 📚 Modules Breakdown

### 🔹 Module 00 — Basics of C++

* Namespaces, classes, member functions
* Input/output streams
* Initialization lists and static members

---

### 🔹 Module 01 — Memory & References

* Stack vs heap allocation
* Pointers and references
* File streams and basic data manipulation

---

### 🔹 Module 02 — Ad-hoc Polymorphism

* Operator overloading
* Orthodox Canonical Form
* Fixed-point arithmetic

---

### 🔹 Module 03 — Inheritance

* Base and derived classes
* Method overriding
* Multiple inheritance and the diamond problem

---

### 🔹 Module 04 — Subtype Polymorphism

* Virtual functions
* Abstract classes
* Interfaces (pure virtual classes)

---

### 🔹 Module 05 — Exceptions

* Try/catch blocks
* Custom exceptions
* Error handling strategies

---

### 🔹 Module 06 — Type Casting

* `static_cast`, `dynamic_cast`, `reinterpret_cast`
* Scalar conversions and type safety

---

### 🔹 Module 07 — Templates

* Function templates
* Class templates
* Generic programming patterns

---

### 🔹 Module 08 — Containers & Algorithms

* STL containers
* Iterators
* Algorithm usage and customization

---

### 🔹 Module 09 — STL & Advanced Usage

* Maps, stacks, vectors, deques

## ⚙️ Compilation & Usage

Each exercise can typically be compiled using `make`.

```bash
# Clone the repository
git clone https://github.com/Expl0-it/cpp_modules.git

# Navigate to a module/exercise
cd cpp_modules/00/ex00

# Compile
make

# Run
./program_name
```

> ⚠️ Most exercises are designed to compile with:

```
-std=c++98
```
